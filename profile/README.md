# Pulsonix

> Pulsonix keeps the schematic editor, PCB layout, and copper routing on one board outline so placed parts stay tied to the nets on the desk.

## Four Beats

1. **Name the outline.** Give the Pulsonix session a short title before you place parts or copper.
2. **Pin the live parts.** Keep current nets and the board outline on the Pulsonix board and leave unused packages aside.
3. **Check the copper.** Read the Pulsonix summary of PCB layout before you treat a route as final.
4. **Close the loop.** Note which nets are ready so the next Pulsonix visit does not start by hunting the schematic editor.

## First Questions

**Does Pulsonix replace the printed board outline?**  
No. Pulsonix sits beside the schematic sheets and copper prints you already use.

**Can two electronics engineers share one computer?**  
Yes. Each person keeps a separate Pulsonix profile.

**Will Pulsonix stay workable on an older office laptop?**  
Yes. Pulsonix is meant to stay light during a normal design review.

**What should a new user try first?**  
One small Pulsonix schematic today, then the same PCB layout again tomorrow.

## Field Note

Pulsonix is easier to trust when the outline stays smaller than the product it came from. A named session shows which board is active, the pins show which parts you will place today, and the closing note tells the next person which schematic editor view drives the copper routing. That record is short on purpose: not a copy of every package, only the path back to the board that is still open.

The same loop fits a student netlist, a client layout, or a computer shared by two engineers. Open the last Pulsonix session, confirm one net, and leave the copper easier to follow than you found it. Printed sheets stay where they are. Pulsonix only holds the schematic editor, the PCB layout, and the handoff.

## One Real Pass

Pick a board that already has a name: a small analog card, a connector panel, or a short power rail. Open it in Pulsonix, keep only those parts on the board, and read one copper route you can point to. A pass is done when that route stays tied to the schematic editor and the unused packages are no longer in the way. Pulsonix does not need a full rebuild of the outline before it is useful.

If the pass feels crowded, the layout is too wide. Drop anything that belongs to a different board and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first part to the last net, with the summary still matching the copper routing on the board.
